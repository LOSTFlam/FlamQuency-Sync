# FlamQuency-Sync — Design System «Угольки» v3

> **Единственный источник правды по визуалу.** Любой новый экран, компонент
> или стиль ОБЯЗАН брать цвета/отступы/типографику/иконки отсюда. Не
> изобретать свои значения в CSS. Если нужного токена нет — сначала добавить
> его сюда, потом использовать.

**Тема:** «Угольки» (Ember v3 — Огненное Совершенство).
Тёмная глубинная база + многослойные огненно-оранжевые градиенты и свечения.
Бренд: FlamQuency.
Настроение: живое пламя в ночи — уютно, мощно, высокотехнологично и безупречно.

**Версия дизайн-системы:** v3 (v2.0 программы). Единый источник для CLI
(Rich) и TUI (Textual) — палитра описана один раз в `style.py` (CLI) и
`theme.py` (TUI), и тест `test_style_palette_matches_theme` следит, чтобы
они не разъехались.

**Варианты темы:** «Калейдоскоп» (`kaleido.py`) поворачивает только
акцентную шкалу, сохраняя тёмные поверхности и светлый текст. Проверка
контраста по WCAG зашита в тесты — случайная тема не может оказаться
нечитаемой.

## 1. Палитра «Угольки» v3

### 1.1 Поверхности (тёмная глубинная база)

| Токен | Hex | Роль |
|---|---|---|
| `surface` | `#1A1210` | Основной фон приложения — тёмный уголь |
| `surface-raised` | `#241814` | Панели, карточки, боковая навигация, списки |
| `surface-overlay` | `#2E1D18` | Поповеры, выпадающие меню, модальные окна, активные табы |
| `surface-sunken` | `#120C0A` | Вдавленные области: поля ввода, статус-бар, фон терминала |
| `surface-glass` | `#261A16` | Имитация матового стекла при наложении слоёв |

### 1.2 Акценты (градации огня)

| Токен | Hex | Роль |
|---|---|---|
| `accent` | `#FF6B1A` | Основной акцент — логотип, активные рамки, фокус |
| `accent-hot` | `#FF3D00` | Ядро пламени — критические действия, деструктивные кнопки, ошибки |
| `accent-warm` | `#FFB347` | Тёплый свет — hover-состояния, мягкая подсветка текста |
| `accent-deep` | `#B33C00` | Тлеющие угли — границы, тени, неактивные рамки |
| `accent-ember` | `#8A2500` | Глубокий тлеющий уголь — фоновые разделители, лёгкие контуры |
| `accent-glow` | `#FF8A50` | Ореол свечения вокруг активных карточек и индикаторов |

### 1.3 Текст

| Токен | Hex | Роль |
|---|---|---|
| `text` | `#F5E6DC` | Основной текст — тёплый пепельно-белый (высокий контраст) |
| `text-muted` | `#A68B7B` | Второстепенный текст, подписи колонок, метки |
| `text-faint` | `#6B534A` | Плейсхолдеры, отключённые элементы, неактивные хоткеи |
| `text-contrast` | `#1A1210` | Тёмный текст на огненных плашечных кнопках (primary/accent) |

### 1.4 Семантика

| Токен | Hex | Роль |
|---|---|---|
| `success` | `#4CAF50` | Успех синхронизации, валидность, онлайн |
| `warning` | `#FFC107` | Предупреждения, конфликты, облако офлайн |
| `error` | `#E53935` | Ошибки, повреждённые блобы, сбои |
| `info` | `#FF8A50` | Информационные плашки — тёплый фирменный цвет |

> **Правило контраста:** на огненном фоне (`accent`, `accent-warm`) текст ВСЕГДА
> тёмный (`text-contrast` `#1A1210`), никогда белый!

## 2. Эффекты v3 (Свечение, Тени, Стекло, Градиенты)

В терминале эффекты имитируются слоями символов и цветовыми ступенями:

| Эффект | Как достигается | Где применяется |
|---|---|---|
| **Огненное свечение (Glow)** | Двойная рамка (`accent-deep` снаружи, `accent` внутри) либо подсветка границы с ореолом `accent-glow` | Баннеры, фокусные модалки, активный экран |
| **Глубокая тень (Shadows)** | Псевдографика теней (символы ` `, `▄`, `▀`) либо тёмный контур `surface-sunken` вокруг `surface-raised` | Всплывающие меню, модальные диалоги, карточки |
| **Матовое стекло (Glassmorphism)** | Контрастный шаг `surface-glass` поверх `surface-raised` с рамкой `accent-deep` (0.5 контраста) | Toast-уведомления, боковые выпадающие списки |
| **Многослойная глубина (Depth)** | 4-уровневая иерархия: `sunken` (дно) → `surface` (фон) → `raised` (карточки) → `overlay` (всплывающие окна) | Весь TUI |
| **Пламенный градиент (Flame Gradient)** | Переход от `accent-deep` (#B33C00) к `accent` (#FF6B1A) и к `accent-warm` (#FFB347) | Прогресс-бары CLI/TUI, заголовки, чарты |

## 3. Анимации и микро-интеракции (TUI)

- **Плавные переходы:**
  ```css
  Button {
      transition: background 150ms in_out_cubic, color 150ms in_out_cubic, border 150ms in_out_cubic;
  }
  ListItem, .rail-item {
      transition: background 120ms ease_in_out;
  }
  ```
- **Hover-эффекты:** подсветка рамки `accent-warm`, лёгкий сдвиг контраста фона.
- **Пульсация (Pulsing Amber):** элементы в состоянии ожидания фонового процесса (синк, сканирование) циклически переливаются между `accent` и `accent-warm`.
- **Критический огонь:** при необратимых операциях (prune, restore) кнопка и контур окрашиваются в `accent-hot` (#FF3D00).

## 4. Иконки Nerd Font v2 и контекстные состояния

Все иконки — строго из `src/flamquency/icons.py`. При отсутствии шрифта — читаемый ASCII-fallback.

### 4.1 Контекстные состояния иконок:
- **Облако:** `cloud-on` (зелёный/инфо при активном соединении) vs `cloud-off` (жёлтый/красный warning при отсутствии связи).
- **Шифрование:** `lock` (зелёный при активном шифровании) vs `unlock` (серый/text-muted).
- **Синхронизация:** `sync` вращающийся/активный vs `check` при завершении.
- **Хранилище и аналитика:** `graph`, `pie`, `bars` для графиков и визуализации.
- **Планировщик:** `schedule`, `cron`, `clock` для автоматизации.
- **Восстановление:** `restore`, `diff`, `content` для точечной работы с версиями.

## 5. Компоненты дизайн-системы v3

### 5.1 Интерактивный статус-бар
- Расположен вверху экрана, фон `surface-sunken`.
- Отображает профиль, бэкенд, отслеживаемые файлы, размер хранилища, статус шифрования.
- Кликабельные сегменты (клик по «Шифрование» переходит на экран шифрования).

### 5.2 Scrollbars (TUI)
- Кастомный ползунок: `scrollbar-color: #FF6B1A #120C0A;`
- Hover на скроллбаре: `scrollbar-color-hover: #FFB347 #1A1210;`

### 5.3 Поля ввода (Inputs)
- Фон `surface-sunken`, текст `text`.
- В фокусе: рамка `accent` (#FF6B1A) со свечением.
- Плейсхолдер: `text-faint` (#6B534A).

### 5.4 Кнопки (Buttons)
- `primary`: фон `accent`, текст `text-contrast` (#1A1210), жирный шрифт.
- `secondary / default`: фон `surface-raised`, рамка `accent-deep`, текст `text`.
- `destructive`: фон `accent-hot`, текст `#FFFFFF`.
- `success`: фон `success`, текст `text-contrast`.

### 5.5 Toast-уведомления
- Всплывающая плашка в нижней части экрана.
- Фон `surface-glass`, рамка `accent` (или семантический цвет), иконка + текст, автоскрытие через 3-4 секунды.

### 5.6 Контекстное меню
- Появляется по клику / правой кнопке / хоткею в таблицах снапшотов и файлов.
- Пункты: «Восстановить», «Просмотреть содержимое», «Показать Diff», «Удалить».

## 6. Новые функциональные экраны v2.0

1. **RestoreContentScreen:** интерактивный просмотр версий выбранного файла, просмотр содержимого конкретной версии и выбор пути восстановления (`dest_path`).
2. **VisualDiffScreen:** построчный diff двух версий файла с подсветкой зелёный/красный в палитре «Угольки».
3. **ScheduleScreen:** визуальная настройка интервалов автоматической синхронизации (cron/systemd-timer), привязка к профилям, статус таймеров.
4. **StorageAnalyticsScreen:** графики роста объёма хранилища, процент дедупликации, топ самых часто изменяемых файлов.
5. **IgnoreEditorScreen:** интерактивный редактор `.flamquencyignore` с валидацией правил на лету.
6. **Spark / Огниво:** кнопка быстрого действия на дашборде (синк активного профиля + prune).

### 6.1 «Калейдоскоп» — варианты темы

Одна тема на все случая скучна. «Калейдоскоп» берёт базу «Угольков» и
поворачивает **только акцентную шкалу**, сохраняя структуру:

| Вариация | Характер | Акцент |
|:--|:--|:--|
| `fire` | исходные «Угольки» | `#FF6B1A` |
| `magma` | глубже и багровее | `#E62E00` |
| `sunset` | теплее, к янтарю | `#FF8C1A` |
| `inferno` | кислотный розовый жар | `#FF2D78` |
| `ash` | почти монохром | `#9C8F86` |

Правило доступности: **поверхности остаются тёмными, текст — светлым**.
Меняется только акцент, поэтому ни одна вариация не может оказаться
нечитаемой. `kaleido.rotate()` поворачивает тон в HLS, сохраняя светлоту
и насыщенность; `--random` даёт случайную вариацию по seed.

### 6.2 Графики в CLI

CLI не обделён визуализацией: `style.bar_chart()` рисует горизонтальные
бары с градиентом «угольки → ядро пламени», а `style.sparkline()` — тренд
блоками Unicode. Sparkline отсекает выбросы по IQR, иначе один
гигантский первый снапшот сплющил бы всю дальнейшую динамику в линию у
пола.
