# FlamQuency-Sync — Design System «Угольки»

> **Единственный источник правды по визуалу.** Любой новый экран, компонент
> или стиль ОБЯЗАН брать цвета/отступы/типографику отсюда. Не изобретать
> свои значения в CSS. Если нужного токена нет — сначала добавить его сюда,
> потом использовать.

**Тема:** «Угольки» (Ember). Тёмная база + огненно-оранжевые акценты.
Бренд: 🔥 FlamQuency. Настроение: тёплый угольёвый огонь в ночи — уютно,
мощно, надёжно.

---

## 1. Палитра

### 1.1 Поверхности (тёмная база)

| Токен | Hex | Роль |
|---|---|---|
| `surface` | `#1A1210` | Основной фон приложения — тёмный уголь |
| `surface-raised` | `#241814` | Панели, карточки, боковая навигация |
| `surface-overlay` | `#2E1D18` | Поповеры, выпадающие меню, активные табы |
| `surface-sunken` | `#120C0A` | Вдавленные области: поля ввода, статус-бар |

### 1.2 Акценты (огонь)

| Токен | Hex | Роль |
|---|---|---|
| `accent` | `#FF6B1A` | Основной акцент — логотип, активные элементы, заголовки |
| `accent-hot` | `#FF3D00` | Ядро пламени — критические действия, ошибки |
| `accent-warm` | `#FFB347` | Тёплый свет — hover-состояния, вторичный акцент |
| `accent-deep` | `#B33C00` | Угли — границы, тени, неактивные рамки |

### 1.3 Текст

| Токен | Hex | Роль |
|---|---|---|
| `text` | `#F5E6DC` | Основной текст — тёплый белый (не чисто белый!) |
| `text-muted` | `#A68B7B` | Второстепенный текст, подписи, подсказки |
| `text-faint` | `#6B534A` | Плейсхолдеры, disabled, watermark |

### 1.4 Семантика

| Токен | Hex | Роль |
|---|---|---|
| `success` | `#4CAF50` | Успех синка, валидность |
| `warning` | `#FFC107` | Предупреждения, конфликты |
| `error` | `#E53935` | Ошибки, отказ |
| `info` | `#FF8A50` | Информация — тёплый, в духе темы |

> **Правило:** семантические цвета только для семантики. Никогда не
> использовать `success` как декор.

## 2. Типографика

TUI = терминал. Шрифт системный, но **иерархия строится весом и размером**:

| Уровень | Стиль | Где |
|---|---|---|
| Title | bold, `accent` | Заголовок экрана, `app-title` |
| Subtitle | regular, `text-muted` | Подзаголовок под title |
| Section | bold, `text` | Заголовки секций, панелей |
| Body | regular, `text` | Основной контент |
| Label | regular, `text-muted` | Подписи полей, метаданные |
| Faint | dim, `text-faint` | Плейсхолдеры, «not created yet» |

Правила:
- Заголовки **всегда** с эмодзи-иконкой темы (🔥 ⏪ 📁 ⚙️) — узнаваемость экранов.
- Цифры и статусы — жирные; служебный текст — приглушённый.

---

## 3. Отступы и ритм

Единая шкала (в «ячейках» терминала):

```
1 = минимальный (внутри строк)
2 = малый (между связанными элементами)
4 = средний (между секциями)
6+ = большой (от краёв экрана)
```

- Контейнеры: `padding: 1 2` (вертикаль 1, горизонталь 2).
- Кнопки меню: `margin: 0 2 1 2`.
- Панели результата: `margin: 1 2; padding: 1`.

## 4. Компоненты

### 4.1 Боковая навигация (Rail)

Вместо стопки кнопок — вертикальный rail слева:
- Каждый пункт: `иконка + подпись`, активный — фон `surface-overlay` + рамка `accent`.
- Пункты: 🔥 Синк · ⏪ Откат · 📁 Версии · 🔐 Шифр · ⚙️ Настройки.
- Ширина фиксированная (~20 колонок), фон `surface-raised`.

### 4.2 Status-бар (дашборд)

Прибитая к верху полоса `surface-sunken` с ключевыми метриками:
```
Backend: github | Tracked: 18 files | Storage: 0.02 MB | 🔒 on | Profile: default | Last sync: 2h ago
```
- Иконки метрик цветом семантики (🔒 success, 🔓 warning).
- Обновляется после каждого действия.

### 4.3 Кнопки

| Вариант | Фон | Текст | Где |
|---|---|---|---|
| `primary` | `accent` | `#1A1210` (тёмный на огненном!) | Главное действие экрана |
| `default` | `surface-raised` | `text` | Второстепенные |
| `error` | `error` | `#FFFFFF` | Разрушающие действия |
| `success` | `success` | `#1A1210` | Подтверждения |

> **Правило контраста:** на огненном фоне текст ВСЕГДА тёмный (`#1A1210`),
> никогда белый — иначе нечитаемо.

### 4.4 Таблицы (DataTable)

- Заголовки: bold, `text-muted`.
- Активная строка: фон `surface-overlay`.
- Курсор: цвет `accent`.
- Зебра: `surface-raised` / `surface` для читаемости.

### 4.5 Панель результата

- Фон `surface-raised`, рамка `solid accent`.
- Минимальная высота 5 строк.
- Иконка результата: ✅ success / ❌ error / ⚠️ warning.

### 4.6 Пустые состояния

- Центрированный `text-muted` текст + подсказка что делать
  («No snapshots available. Run a sync first.»).

## 5. Экраны

### 5.1 Главный экран (Dashboard)

```
┌─────────────────────────────────────────────┐
│ 🔥 FlamQuency-Sync          [статус-бар]    │
├──────────┬──────────────────────────────────┤
│ 🔄 Синк  │  (контент активного экрана)      │
│ ⏪ Откат │                                  │
│ 📁 Версии│                                  │
│ 🔐 Шифр  │                                  │
│ ⚙️ Настр │                                  │
└──────────┴──────────────────────────────────┘
```

- Rail слева, контент справа. Экраны — не модальные, а swap в правой панели.
- Esc / кнопка «Назад» возвращает на дашборд.

### 5.2 Экран синка

- Выбор источника (Input + текущий дефолт), кнопка «Синхронизировать».
- Прогресс-бар во время работы (см. §6).
- Результат в панели: файлы, блобы, ошибки.

### 5.3 Экран откатa

- Таблица снапшотов: время · файлов · размер.
- Клик/Enter → откат с подтверждением.

### 5.4 Экран версий файла

- Input пути → таблица версий (hash · время · размер).
- Кнопка «Откатить» на выбранной версии.

### 5.5 Экран шифрования

- Статус (вкл/выкл), кнопка enable/disable с вводом пароля.

### 5.6 Настройки

- Бэкенд, исключения, ignore-файл, профили, автосинк — только чтение +
  ссылки на CLI-команды управления.

---

## 6. Движение и фидбек

- Синк в worker-потоке (`@work(thread=True)`) — UI не морозится.
- Прогресс: `ProgressBar` с шагами (скан → хеш → запись → снапшот).
- После действия: тост/статус-строка обновляется мгновенно.
- Никаких бесконечных спиннеров без результата.

---

## 7. Что запрещено (анти-франкенштейн)

1. **Нет** хардкод-цветов (`#ff0000`, `red`, `white`) в CSS/компонентах —
   только токены из этого файла.
2. **Нет** новых отступлеющих от шкалы §3 значений «на глаз».
3. **Нет** смешения стилей: не добавлять «синюю кнопку» в огненную тему —
   семантика важнее разнообразия.
4. **Нет** эмодзи вне набора темы (🔥⏪📁🔐⚙️✅❌⚠️🔒🔓).
5. Любой новый токен сначала в DESIGN.md, потом в коде.

## 8. Маппинг на Textual

| Токен | Textual CSS |
|---|---|
| `surface` | `$surface` (переопределить в теме) |
| `accent` | `$primary` / `$accent` |
| `text-muted` | `$text-muted` |
| `success`/`warning`/`error` | `$success`/`$warning`/`$error` |

Тема регистрируется через `App.register_theme` (см. `theme.py`), CSS
ссылается только на переменные темы.
